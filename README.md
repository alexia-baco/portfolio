# 👩‍💻 Portfolio Personal - Alexia Baco

¡Hola! 👋 Bienvenido/a al repositorio de mi portfolio personal. 

Soy Alexia, vengo del mundo audiovisual y del sonido en directo, y actualmente estoy cursando mi segundo año de Desarrollo de Aplicaciones Web (DAW) en CESUR. 

He montado esta web desde cero (sin plantillas ni *frameworks* pesados) con el objetivo de tener un espacio limpio y minimalista donde enseñar mis proyectos y mi evolución técnica mientras busco mi primera oportunidad como **Junior Web Developer**.

🔗 **[Puedes ver la web en vivo aquí](https://alexia-baco.github.io/portfolio/)**

---

## 🛠️ Tecnologías que he usado

Para este proyecto quería centrarme en los fundamentos y demostrar que puedo hacer una maquetación limpia y *responsive* a mano. 

*   **HTML5:** Estructura semántica multipágina y accesible.
*   **CSS3:** Maquetación pura utilizando `Flexbox` y `CSS Grid`. Uso de variables nativas (Custom Properties) para mantener la paleta de colores coherente.
*   **JavaScript (Vanilla):** Un pequeño *script* para controlar la lógica visual y el efecto secuencial de "subrayado de rotulador" al cargar la página.
*   **Despliegue:** GitHub Pages.

---

## 📂 Estructura del Proyecto

He optado por una arquitectura multipágina clásica para mantener el código ordenado y separado por contextos:

*   `index.html` - El "Hero" principal con mi titular y animación.
*   `sobre-mi.html` - Mi background, mi transición del mundo audiovisual al IT y mi *stack* tecnológico.
*   `proyectos.html` - Cuadrícula interactiva con mis repositorios más destacados (TuFit 360, Code Arts, etc.).
*   `contacto.html` - Enlaces directos a mis redes y correo sin fricciones.
